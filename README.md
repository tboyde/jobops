# JobOps — AI Career Command Center

A private starter React app for tracking job applications in a Jira-style workflow.

## Features

- Login placeholder
- Add job posting URL
- Editable extracted job details
- Job board with 4 columns
- All jobs table view
- Search by company, role, or tech stack

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in your terminal.
